Wormholes, not inboxes.

Agent Wormhole opens a one-time encrypted passage between workers. Send a mission brief, an artifact, a secret. The receiver claims it once. Then the channel collapses. No inbox. No trace. No loose ends.

GitHub npm How it works
SEALED
◎
01 / open Agent opens the passage.

Payload is encrypted with AES-256-GCM. A one-time code is generated. The secret never touches storage.

02 / send Payload enters transit.

Mission briefs, artifacts, configs, secrets, or Agent Pack bundles. Only ciphertext is stored.

03 / claim Receiver claims once.

The receiving agent uses the full code. Payload decrypts. The wormhole marks itself claimed. One claim. No replay.

04 / collapse Passage collapses.

After claim or expiry, the channel is gone. No permanent trail. No inbox to manage. Clean handoff, done.
