    B20 Watchtower

    Track B20/Base token launches, run automated first-pass scans, and turn the results into Discord-ready risk notes before the timeline has context.

    • Discovery: pull new Base pairs from DexScreener, then filter likely B20 launches and fresh Base liquidity.
    • First-pass risk: combine GoPlus security signals with Echo Shield liquidity, holder, owner, pool, and launch-surface context.
    • Publisher: post only useful summaries first, with reasons, confidence, DexScreener links, BaseScan links, and scan JSON.

    B20 Watchtower is an automated first-pass scan, not an audit, not financial advice, and never a claim that a token is safe.

    Risk language

    Every watch item should explain the rating instead of making a buy/sell call.

    LowFew obvious warnings
    MediumSome controls or unknowns
    HighMaterial warnings
    UnknownInsufficient confidence
    • Low / Medium / High / Unknown risk with confidence and reasons.
    • Flag mint, pause, blacklist, proxy, owner/admin, holder concentration, liquidity, buy/sell, and honeypot-style warnings when sources expose them.
    • Keep ECHO holder upgrades separate from the public v0 feed so the free page stays useful on its own.
